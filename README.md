# Коробки: учёт вещей в Home Assistant

Панель в боковом меню: дом → места (кладовки) → коробки → вещи. К позициям можно добавить до 8 фото и напечатать QR-этикетку. Вещам можно ставить категории (хештеги) и пометки. Данные и фото хранятся в Home Assistant, копия лежит на устройстве, поэтому панель работает без сети и синхронизируется потом.

Версия: 0.10.3 (показана внизу панели).

## Установка

1. Скопируйте `custom_components/korobki` в `/config/custom_components/`.
2. Добавьте в `configuration.yaml`:
   ```yaml
   korobki:
   ```
3. Полностью перезапустите Home Assistant.
4. В боковом меню появится «Коробки».

Установка через HACS: добавьте репозиторий как пользовательский (категория «Integration») и перезапустите Home Assistant.

## Приложение для iPhone

Для подвала и кладовки удобнее отдельное приложение на экране «Домой»:

1. В Home Assistant: профиль → «Безопасность» → «Долгосрочные токены доступа» → создайте токен «Коробки».
2. В Safari откройте `https://ваш-адрес-ha/korobki_app/index.html`, вставьте токен, дождитесь загрузки данных.
3. «Поделиться» → «На экран Домой».

Рекомендуется создать отдельного пользователя `korobki` без прав администратора и токен создавать от его имени: отзыв не затронет остальное.

Синхронизация идёт, пока приложение открыто. Перед выходом из подвала откройте приложение и дождитесь значка «Синхронизировано».

## Работа без связи

Без сети можно добавлять и править места, коробки, вещи, категории и фото. Изменения копятся на устройстве, вверху показано, сколько ждёт отправки. Когда связь появляется, всё отправляется само, а чужие правки приходят обратно. Кнопка «Синхронизировать» внизу запускает обмен вручную.

Первый запуск на каждом устройстве требует связи: данные скачиваются целиком.

## Обновление

Данные и фото лежат отдельно от кода (`/config/.storage/korobki`, `/config/korobki_photos/`), при обновлении не затрагиваются. Всё же делайте резервную копию Home Assistant перед обновлением.

1. Замените содержимое `custom_components/korobki` (или обновите через HACS).
2. Полностью перезапустите Home Assistant.
3. Номер версии внизу панели должен совпасть с новым. Если нет, закройте приложение полностью и откройте снова.

## Данные и копии

- Записи: `/config/.storage/korobki`
- Фото: `/config/korobki_photos/`
- Автокопии (раз в сутки, последние 14): `/config/korobki_backups/`. Фото в файл не входят, они попадают в обычную копию Home Assistant.
- «Сервис» в панели: скачать копию (с фото или без), восстановить из файла с проверкой, очистить фото на сервере.

Если автокопия не создана, появляется уведомление Home Assistant и событие `korobki_backup_failed`.

Чтобы убрать интеграцию, удалите строку `korobki:` и перезапустите Home Assistant. Данные и фото останутся на диске.

## Голосовой поиск

После перезапуска доступны фразы для Assist: «где лежит молоток», «где моя дрель». Те же данные отдаёт действие `korobki.find` (поле `query`) для скриптов и автоматизаций.

## Ограничения

- Сенсоров и автоматизаций по вещам пока нет.
- Категории назначаются только вещам.
- Общие данные доступны любому пользователю Home Assistant с доступом к панели.
- QR-код ведёт на адрес длиной до 106 символов.

## Для разработки

- Интерфейс: исходники в `frontend_src/`, сборка `python3 build_frontend.py` (проверка `--check`). Собранный файл коммитится вместе с исходниками.
- Тесты: `python3 tests/run_tests.py` (`--fast` без браузерных).
- Версия задаётся только в `custom_components/korobki/manifest.json`.
- Подробности архитектуры, история версий и план изменений ведутся в документах проекта.
