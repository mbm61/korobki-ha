# Коробки: учёт вещей в Home Assistant

Панель в боковом меню: дом → места (кладовки) → коробки → вещи. К любой позиции можно добавить до 8 фото и напечатать QR-этикетку. Вещам можно ставить категории (хештеги) и писать пометки. Данные и фото хранятся в Home Assistant, копия лежит на устройстве.

Версия: 0.5.2 (она же показана внизу панели). Работает без связи с сервером и потом синхронизируется.

## Установка

1. Скопируйте папку `custom_components/korobki` из архива в `/config/custom_components/` (в Home Assistant OS это `/homeassistant/custom_components/`). Файл `__init__.py` должен лежать прямо в `korobki`, без лишних папок.
2. В `configuration.yaml` добавьте строку:
   ```yaml
   korobki:
   ```
3. Полностью перезапустите Home Assistant (не «Перезагрузить YAML»).
4. В боковом меню появится пункт «Коробки».

## Что умеет панель

- **Что куда добавляется.** В дом добавляются места, в место коробки и вещи (по умолчанию коробка), в коробку вещи и вложенные коробки (по умолчанию вещь).
- **Категория при добавлении вещи.** В форме добавления вещи можно сразу отметить категории или вписать новую.
- **Название дома.** Нажмите на карандаш рядом с заголовком, чтобы переименовать дом, место или коробку.
- **Категории.** Плашка «Категории» в правом верхнем углу открывает список категорий: создать, переименовать («Править»), удалить. Нажатие на категорию показывает все вещи с ней по всему дому. В карточке вещи категории выбираются нажатием, а новая создаётся прямо там.
- **Пометки.** В карточке вещи есть поле «Пометка» (срок годности, размер, где купили). Поиск находит вещи по названию, пометке и категории. Запрос `#зимнее` ищет по категории.
- **Назад.** Стрелка слева вверху поднимает на уровень выше, закрывает поиск или список категорий. Внутри листа (фото, QR) стрелка возвращает к предыдущему листу.
- **QR-этикетки.** Кнопка «QR» у коробки, места или вещи. Режим «В приложении HA» открывает приложение Home Assistant сразу на нужной коробке. Режим «В браузере» ведёт на адрес вашего HA. Этикетку сохраняйте долгим нажатием на картинку, кнопка «Этикетки» собирает лист для всех вложенных коробок.

## Работа без связи (подвал, кладовка)

Панель и приложение хранят полную копию данных и фото на устройстве. Без связи можно добавлять и править места, коробки, вещи, категории и фото. Изменения копятся на устройстве, вверху показано «Нет связи. Изменения сохранены на устройстве: N». Когда связь появляется, всё отправляется на сервер само (при открытии, при возвращении в приложение, раз в минуту), а чужие правки приходят обратно. Кнопка «Синхронизировать» внизу запускает обмен вручную.

Первый запуск на каждом устройстве требует связи: данные скачиваются целиком.

### Установка приложения на iPhone (рекомендуется для подвала)

Панель внутри приложения Home Assistant без сети может не открыться. Поэтому есть отдельное приложение, которое запускается с экрана «Домой» и открывается даже в режиме полёта.

1. Создайте токен: в Home Assistant профиль (внизу слева) → «Безопасность» → «Долгосрочные токены доступа» → «Создать токен», имя «Коробки». Скопируйте его.
2. В Safari откройте `https://ваш-адрес-ha/korobki_app/` (адрес с HTTPS, как открываете Home Assistant).
3. Вставьте токен и нажмите «Войти». Дождитесь, пока загрузятся данные.
4. «Поделиться» → «На экран Домой». Дальше запускайте «Коробки» с иконки.
5. Один раз откройте приложение дома и убедитесь, что данные видны, потом пробуйте без сети.

Токен хранится только в этом приложении. Если его отозвать в профиле, приложение попросит ввести новый («Выйти» внизу тоже сбрасывает его).

На компьютере можно пользоваться боковой панелью «Коробки» или тем же адресом `/korobki_app/`.

### Что важно знать

- Приложение на экране «Домой» и Safari хранят данные отдельно. Каждое при первом открытии скачивает данные заново.
- iOS не отправляет данные в фоне. Синхронизация идёт, пока приложение открыто. Вернулись из подвала, открыли приложение, подождали значок «Синхронизировано».
- Если iOS долго не использует приложение, он может очистить хранилище. Всё, что уже отправлено на сервер, не пропадёт. Не закрывайте подвал, оставив несинхронизированные правки на неделю.
- Правки из разных мест объединяются по каждой записи отдельно: у вещи и у коробки своя метка времени. Если одну и ту же вещь изменить на двух устройствах, останется более поздняя правка. Разные вещи не мешают друг другу.
- QR-код при сканировании камерой открывает приложение Home Assistant или браузер, а не установленное «Коробки». Для открытия страницы нужна связь.

## Возможности 0.5.0

- **Цвет.** В листе места или коробки выберите цвет, он задаёт обложку и рамку. У коробки можно оставить «Как у места».
- **Кнопки внизу.** «Домой» (слева) ведёт в корень дома, «Назад» поднимает на уровень выше. В самом корне панель скрыта.
- **Корзина.** Удалённые места, коробки и вещи хранятся 30 дней: «Корзина» внизу страницы или в «Сервисе». «Вернуть» возвращает всё вместе с содержимым. При удалении всплывает подсказка, сколько вещей уйдёт вместе с коробкой. Фото из корзины удаляются с сервера только через 30 дней или по кнопке «Очистить корзину».
- **Перенос и копия.** В листе вещи, коробки или места есть «Переместить» (выбор нового места из списка) и «Копировать» (копия без фото, с пометкой «копия»).
- **Список вещей.** В форме добавления вещи галочка «Списком»: по одной вещи в строке, количество так: `Шапки x4`. Галочка «Добавлять подряд» оставляет форму открытой и помнит выбранные категории.
- **Поиск и фильтры.** Кнопка воронки справа от поиска: несколько категорий сразу, «Без категории», «Без фото», порядок (по расположению, по названию, сначала новые или старые). В результатах виден путь «Дом › Кладовка › Коробка».
- **Сервис** (внизу страницы). Скачать копию (данные или с фото), восстановить из файла, состояние защиты данных на устройстве, фото на сервере (сколько, сколько лишних, кнопка очистки).
- **Предупреждение.** Если правки не уходили на сервер больше двух дней, плашка вверху краснеет.
- **Защита хранилища.** Приложение просит iOS не удалять его данные. Это работает надёжно, когда приложение добавлено на экран «Домой».
- **Плашка «Категории»** скрыта на страницах самих категорий.

### Голосовой поиск «где лежит дрель?»

После перезапуска интеграция добавляет фразы для Assist (файлы `custom_sentences/ru/korobki.yaml` и `en/korobki.yaml` в папке конфигурации, существующие не перезаписываются). Скажите или напишите ассистенту: «где лежит молоток», «где моя дрель». Ответ: «Молоток: коробка Инструменты, место Кладовка».

Если ассистент не понял фразу, в «Настройки → Голосовые ассистенты» убедитесь, что язык ассистента русский, и перезапустите Home Assistant ещё раз. Те же данные отдаёт действие `korobki.find` (поле `query`), его можно использовать в скриптах и автоматизациях.

### Отдельный пользователь для приложения (рекомендуется)

Токен хранится в приложении на телефоне. Чтобы потеря телефона не открыла лишнего:

1. «Настройки → Люди → Пользователи» → добавить пользователя `korobki`, права «Администратор» не давать, поставить «Только локальный доступ» если приложением пользуетесь только дома.
2. Один раз войдите под этим пользователем (в окне инкогнито), в его профиле создайте долгосрочный токен.
3. Этот токен вставьте в приложение «Коробки». Отозвать его можно в профиле этого пользователя, остальное не затронется.

Права внутри «Коробок» одинаковые для всех, у кого есть токен или доступ к панели.

## Обновление

Данные и фото при обновлении не затрагиваются: они лежат отдельно от кода, в `/config/.storage/korobki` и `/config/korobki_photos/`. Перед обновлением всё равно сделайте обычную резервную копию Home Assistant.

**Способ 1. Вручную (проще всего).**
1. Распакуйте новый архив и замените содержимое папки `custom_components/korobki` на новое.
2. Полностью перезапустите Home Assistant.
3. Откройте панель. Если вверху появилась плашка «Вышла новая версия панели», нажмите «Обновить». Номер версии внизу панели должен совпасть с новым.

Если плашки нет, а версия старая, закройте приложение Home Assistant на iPhone полностью и откройте снова.

**Способ 2. Через HACS (обновление кнопкой).**
1. Создайте свой репозиторий на GitHub и положите в корень содержимое архива: папку `custom_components`, файлы `README.md` и `hacs.json`. В `manifest.json` замените адреса `documentation` и `issue_tracker` на адрес вашего репозитория.
2. В HACS откройте меню справа вверху → «Пользовательские репозитории», добавьте адрес репозитория, категория «Integration».
3. Установите «Коробки» из HACS и перезапустите Home Assistant.
4. Чтобы выпустить обновление, поменяйте `version` в `manifest.json` и создайте на GitHub релиз с тем же номером. HACS покажет кнопку «Обновить».

Номер версии задаётся в одном месте, в `manifest.json`. Он же подставляется в адрес скрипта панели, поэтому после перезапуска браузер и приложение подхватывают новый код.

## Иконка

Иконка интеграции лежит в папке `brand/` (`icon.png`, `logo.png` и их версии для тёмной темы и `@2x`). Home Assistant показывает такие картинки в «Настройки → Устройства и службы» начиная с версии 2026.3. В более старых версиях вместо неё будет заглушка. Значок в боковом меню (`mdi:package-variant-closed`) от версии HA не зависит.

## Где лежат данные

- Записи (места, коробки, вещи, категории): `/config/.storage/korobki` (старые данные 0.3.0 переносятся сами при первом запуске)
- Фото: `/config/korobki_photos/` (основное и миниатюра)

## Как это устроено

- Если изменить данные на одном устройстве, остальные подхватят правки при следующей синхронизации (сразу, если открыты).
- Любой пользователь Home Assistant, у которого есть доступ к боковому меню, видит панель и может менять данные.
- Чтобы убрать интеграцию, удалите строку `korobki:` и перезапустите HA. Данные и фото останутся на диске.

## Ограничения

- Сенсоры (число вещей, «что лежит в коробке») и автоматизации пока не добавлены.
- Категории относятся только к вещам, коробкам и местам их присвоить нельзя.
- Версия QR ограничена адресом до 106 символов. Для обычных адресов этого хватает.
